## Reflection

The easiest part of this assignment was creating the fixed grade values and calculating the total and average. The hardest part was remembering that JavaScript months begin at zero, so one must be added to the month returned by the `Date` object. I learned that the `Date` object provides separate methods for retrieving the month, day, and year. I also learned that the `Number` object can convert strings and check whether the results are valid numbers or integers. Finally, I learned that JavaScript can display calculated results directly in the browser by updating HTML elements through the DOM.
